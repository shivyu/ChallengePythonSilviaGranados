📊 Challenge Data Science - Análisis de Tiendas
Descripción
Análisis exploratorio de datos de 4 tiendas para identificar patrones de ventas, facturación y satisfacción del cliente.

🎯 Objetivos del Análisis
	1. Facturación Total - Comparación de ingresos entre tiendas
	2. Ventas por Categoría - Identificación de productos más demandados
	3. Calificación Promedio - Medición de satisfacción del cliente
	4. Productos Top/Bottom - Análisis de productos más y menos vendidos
	5. Costo de Envío - Evaluación de gastos promedio por tienda

🛠️ Tecnologías
	* Python 3
	* Pandas
	* Google Colab

📈 Resultados Clave
	* Tienda 1: Mayor facturación (S/. 1,150M)
	* Categoría líder: Muebles y Electrónicos
	* Calificación promedio: 3.98 - 4.05 estrellas
	* Costo envío: S/. 23K - S/. 26K promedio

📂 Datasets
4 archivos CSV con información de ventas, productos, precios y calificaciones.
